# rcj-voice · 声音定制站（voice.955827.xyz）

面向海外华语用户的声音定制 / 歌曲演唱展示站。深夜暖调 UI、三语（中 / 繁 / EN）、试听卡片流。

## 核心原理（How it works）

- **展示与交易分离**：本站只做「试听 + 歌词滚动 + 情绪价值」，**不收款、不发货**。成交一律引导到 shop.955827.xyz（祝福语音 / 定制清唱商品），站内购买按钮只跳转商城，不出现站内支付。
- **三语一源**：中 / 繁 / EN 三套文案都由 `products.json` 驱动（每首歌三语标题 / 标签 / 点评），切换语言只是换字典，不改页面结构。
- **试听流**：`products.json` 现有 **45 首**曲目，每首 `preview` 指向 R2 直链（`https://cdn.955827.xyz/music/*.m4a`，与博客共用 R2 桶），点卡片播放并滚动对应歌词；`lyrics` 是带时间戳（`{t, text}`）的逐行歌词数组。**音频只存 R2，仓库不存音频二进制**。
- **真实不修饰**：主打「不一定完美，但是真实」的原声清唱人设——点评文案区分「清唱版 / 原作者原声 / 励志彩蛋」等类型，不欺骗用户。
- **埋点 → 主站后台**：页面上报匿名访问数据到主站 955827.xyz 的埋点通道（D1 只存匿名统计），主站管理后台可看 voice 流量，**不存个人可识别信息**。

## 文件

- `index.html` — 单文件页面（自包含 CSS/JS，三语切换、卡片流、实时成交条、试听播放、歌词滚动）
- `products.json` — 歌曲数据（三语标题 / 标签 / 点评 + `price`（¥32–46）+ `preview` R2 直链 + `grad` 封面渐变色 + `lyrics` 时间轴）。**改这里即可更新曲库，无需动代码**。

## 数据说明

- 页面加载时 `fetch('products.json')`，成功用线上数据；本地 `file://` 打开时 fetch 被浏览器拒绝，自动回退到 JS 内置的示例数据（fallback，价格与线上曲库不同，仅用于本地预览）。
- 每首歌 `preview` 字段：指向 R2 直链后自动真实播放；为 `null` 时显示模拟试听。
- `grad` 字段：封面渐变色（两色），没有独立封面图。
- `lyrics` 字段：`[{ t: 秒, text: '歌词' }]`，播放时按时间高亮并滚动。

## 部署（CF Pages，纯静态）

1. **GitHub 仓库**：`Bortala5827/rcj-voice`，`main` 分支。
2. **CF Pages**：项目 `rcj-voice` 连接该仓库（生产分支 `main`），构建命令留空，输出目录 `/`；push 自动构建。
3. **域名**：Pages 项目 → Custom domains → `voice.955827.xyz`（CF 自动加 DNS 记录）。
4. **R2 试听音频**：音频放在 R2 桶 `blog-media` 的 `music/` 下，经 `cdn.955827.xyz` 分发（与 rcj-blog 共用；缓存一年）。
5. **更新曲库**：改 `products.json` 的 `songs` 后 push，自动更新。
